# 夜读室

一个安静的阅览室，用 three.js 画在页面的 canvas 上。没有后端，没有账号，没有文字输入；页面上
能看到的只有光、书和一间屋子。访问者的数据不进服务器，连接信息只存在浏览器内存里。

## 现在的状态

- `proto/` 是照着参考照片调出来的光照样张，完整可跑：房间、道具、灯、空气、泛光与调色。
- 根目录的 `index.html` 与 `src/` 是把样张做成成品的方向，还没有写 `src/main.ts`，所以此刻从根
  目录跑起来会失败。先看 `proto/`。

## 跑起来

```sh
cd proto
pnpm install
pnpm dev        # http://127.0.0.1:5173
```

样张里数字键 1 到 4 切换机位，拖动环视。

## 目录

| 路径 | 什么 |
| --- | --- |
| `proto/` | 光照样张，参考实现 |
| `src/`, `index.html` | 成品页面的骨架，未完 |
| `ref/` | 参考照片与网页截图，本地参考，不随站点发布 |
